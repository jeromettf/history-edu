# 위인 그림책 ↔ 한글 쏙쏙(포켓몬 앱) 연결 규칙

두 앱은 GitHub Pages의 같은 주소 아래에 있어서 브라우저 저장소(localStorage)를 함께 씁니다.

- 위인 그림책: https://jeromettf.github.io/history-edu/ (저장소 jeromettf/history-edu)
- 한글 쏙쏙: https://jeromettf.github.io/hangulplay/ (저장소 jeromettf/hangulplay)

같은 기기, 같은 브라우저에서 열 때만 이어집니다. claude.ai에 올린 그림책 페이지는 주소가 달라서 이어지지 않습니다.

## 누가 무엇을 쓰나

| 키 | 쓰는 쪽 | 읽는 쪽 | 내용 |
|---|---|---|---|
| `wiin_bridge_v1` | 그림책 (`js/bridge.js`의 `wbMark`) | 포켓몬 앱 (`wbSync`, `wbItems`) | 책마다 읽음 · 들려줌 · 해 봄 기록 |
| `pkmn_wiin_v1` | 포켓몬 앱 | 포켓몬 앱 | 이미 준 보상 (책 × 단계마다 한 번) |

그림책은 기록만 남기고 보상을 직접 주지 않습니다. 보상은 포켓몬 앱이 열리거나 다시 보일 때 스스로 읽어서 줍니다. 그림책을 읽는 동안 보상 생각을 덜 하게 하려는 설계입니다.

`wiin_bridge_v1` 모양:

```json
{ "v": 1, "at": 1794487554503,
  "books": { "yisunsin": { "no": 36, "who": "이순신", "title": "이순신과 거북선", "type": "지키기",
                            "e": "🐢", "item": "거북선", "read": 1794487554503, "told": 0, "tried": 0 } } }
```

`read`, `told`, `tried`는 처음 기록한 시각(ms)이고, 없으면 아직 안 한 것입니다. `tried`는 "해 봤어요"를 끄면 지워지지만, 이미 준 보상은 되돌리지 않습니다.

## 보상 단계

| 단계 | 그림책에서 기록되는 조건 | 포켓몬 앱 보상 |
|---|---|---|
| read 끝까지 읽기 | 끝 장면에 닿았을 때, 이야기 쪽의 70% 이상을 2.5초 넘게 봤거나 저절로 읽기로 들음 | 공부 스티커 1개 + 박물관 "위인 전시실"에 그 책 물건 전시. 박물관이 없으면 지어 줌 |
| told 들려주기 | "네가 들려줘" 모드로 끝 장면까지 가서 부모가 "아이가 이야기를 들려줬어요"를 누름 | 공부 스티커 2개, 전시품에 ✨ |
| tried 해 보기 | 책 끝 "해 보기" 활동 후 "해 봤어요"를 누름 | 새 친구 카드 1장 (`rwNewCard('wiin')`), 전시품에 ⭐ |

- 위인 그림책은 공부 활동입니다. 포켓몬 앱의 `RW_LEARN`에 `wiin`이 들어 있어서 공부 스티커로 쌓이고, 10개면 새 친구가 옵니다.
- 같은 책, 같은 단계의 보상은 한 번만 줍니다.
- 연결 전에 이미 읽은 책과 해 본 활동은 그림책이 처음 열릴 때 한 번 기록합니다(`wiin-bridge-seeded`).

## 고칠 때 지킬 것

- 키 이름과 `books` 모양을 바꾸면 두 저장소를 함께 고칩니다. 모양이 크게 바뀌면 `v`를 올립니다.
- 전시품 이모지와 이름은 그림책의 `WIIN_DEX`(`js/bridge.js`)가 정합니다. 포켓몬 앱에는 따로 표가 없습니다.
- 포켓몬 앱의 백업 파일은 `pkmn_`로 시작하는 키만 저장합니다. 그래서 `pkmn_wiin_v1`은 백업되고, `wiin_bridge_v1`은 그림책 쪽 기록이라 백업되지 않습니다.
