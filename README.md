# 우리 집 위인 그림책

3살·5살 아이에게 읽어 주려고 만든 한국사 위인 그림책입니다. 「한국을 빛낸 100명의 위인들」에 나오는 인물을 중심으로 40명을 골라, 동화책처럼 한 장면씩 넘기며 읽도록 만들었습니다.

모든 책은 같은 틀을 따릅니다. 무언가를 좋아한 아이 → 사람들이 겪던 곤란한 일 → 그 사람이 한 일 → 지금 우리 곁에 남은 것. 책마다 그림을 눌러 보는 장면이 하나씩 있고, 끝까지 읽으면 책장에 별 스티커가 붙습니다. 마지막 쪽에는 3살용·5살용 이야기 나누기 질문과 부모님 메모가 있습니다.

## 구조

- `index.html`: 화면 뼈대와 스타일
- `js/art.js`: 그림 라이브러리 (손그림 질감, 인물, 동물, 소품, 시대·계절별 배경)
- `js/books/NN-이름.js`: 책 한 권씩. 쪽 배열과 이야기 나누기 질문, 부모님 메모
- `js/redraw/r1~r4.js`: 책마다 두 장면을 구도부터 다시 그린 그림. `redraw('책 id', 쪽 번호, ()=>SVn(...))`로 원래 그림을 바꿔 끼웁니다.
- `js/app.js`: 책장, 넘기기, 읽어주기, 시간의 길
- `build.py`: 모든 파일을 한 장짜리 HTML(`dist/wiin.html`)로 묶음

## 새 책 더하기

1. `js/books/`에 `NN-이름.js`를 만들고, 맨 앞에서 `setScene('시대','계절')`을 불러 배경을 정한 뒤 기존 책 하나를 본떠 `BOOKS.push({...})`로 등록합니다. `teaser`는 앞 권 마지막 쪽에 "다음 이야기"로 나오는 한 줄입니다.
2. `era`는 `gojoseon`, `samguk`, `goryeo`, `joseon`, `modern`, `hyeondae` 가운데 하나입니다.
3. `index.html` 아래쪽 `<script>` 목록에 시대 순서에 맞춰 끼워 넣습니다. 권 번호와 다음 권 연결은 이 순서대로 자동으로 정해집니다.
4. 배경은 `hills()`(들판), `palace()`(궁궐), `room()`(방), `yard(y)`(마당), `sea(y)`(바다)를 쓰면 시대와 계절에 맞게 그려집니다.
5. 그림을 눌러 보는 장면은 쪽에 `taps:[{label, el, say}]`를 넣고, SVG 안의 해당 부분을 `<g id="el">`로 감쌉니다. `show`, `hide`에 id를 주면 눌렀을 때 그림이 바뀌고, 같은 그림에 여러 동작을 걸면 누를 때마다 차례로 돌아갑니다.

전해 오는 이야기와 기록된 사실은 장면 위 표시와 부모님 메모로 구분했습니다.
