# 우리 집 위인 그림책

3살·5살 아이에게 읽어 주려고 만든 한국사 위인 그림책입니다. 「한국을 빛낸 100명의 위인들」에 나오는 인물을 중심으로 60명을 골라, 동화책처럼 한 장면씩 넘기며 읽도록 만들었습니다.

모든 책은 같은 틀을 따릅니다. 무언가를 좋아한 아이 → 사람들이 겪던 곤란한 일 → 그 사람이 한 일 → 지금 우리 곁에 남은 것. 책마다 그림을 눌러 보는 장면이 하나씩 있고, 끝까지 읽으면 책장에 별 스티커가 붙습니다. 끝에는 3살용·5살용 이야기 나누기 질문과 부모님 메모, 그리고 집에서 10분이면 하는 "해 보기" 활동이 있습니다. 활동마다 2022 개정 교육과정의 기초소양(언어·수리·디지털)과 핵심역량(자기관리, 지식정보처리, 창의적 사고, 심미적 감성, 협력적 소통, 공동체) 가운데 두 가지를 표시했고, "해 봤어요"를 누르면 책장 위에 역량별로 쌓입니다. "▶ 저절로 읽기"를 누르면 쪽마다 글을 읽고, 그림 누르기 장면은 하나씩 눌러 보여 준 뒤 다음 쪽으로 넘어가며 끝 장면에서 멈춥니다. 책마다 한 번 "생각 멈춤"이 있어서, 표지에서 먼저 질문을 보여 주고 답이 나오기 바로 앞 쪽에서 다시 묻습니다(`js/think.js`). 저절로 읽기도 여기서 멈추고 "이어서 읽기"로 계속합니다. 책 끝 이야기 나누기는 생각 멈춤과 겹치지 않는 질문 하나만 보이고 나머지는 접어 둡니다. 다 읽은 책은 "네가 들려줘"를 켜면 글을 가리고 첫 쪽과 마지막 쪽에만 물음을 보여 아이가 그림을 보며 이야기를 들려주고, 원래 문장은 접어 둔 칸에서 부모가 볼 수 있습니다.

책장은 조선의 책장 그림 "책가도"를 본떠 쪽빛 바탕에 금선으로 그렸고, 책 읽는 화면은 글이 잘 읽히도록 한지 바탕입니다. 맨 위에 오늘 읽을 책(이어 읽기, 또 읽기, 새 책), 그 아래 "어떤 사람 이야기가 좋아?" 그림 단추, 시대별 책장 칸이 이어집니다. 책장 아래 "위인 도감"에서 읽은 위인을 나라·지키기·과학·기록·예술·마음·독립 일곱 갈래로 나눠 볼 수 있습니다. 끝까지 읽은 책, 아이가 다시 들려준 책, 해 본 활동은 같은 기기의 포켓몬 앱(한글 쏙쏙)에 공부 스티커와 박물관 전시품, 새 친구 카드로 이어집니다. 연결 규칙은 `docs/BRIDGE.md`에 있습니다.

## 구조

- `index.html`: 화면 뼈대와 스타일
- `js/art.js`: 그림 라이브러리 (손그림 질감, 인물, 동물, 소품, 시대·계절별 배경)
- `js/books/NN-이름.js`: 책 한 권씩. 쪽 배열과 이야기 나누기 질문, 부모님 메모
- `js/redraw/r1~r7.js`: 구도부터 다시 그린 장면과 본문에 맞춰 고친 장면. `redraw('책 id', 쪽 번호, ()=>SVn(...))`로 원래 그림을 바꿔 끼웁니다.
- `js/bg/bg.js`: 그림 생성 도구로 만든 배경 10장(webp). `bgImg('이름')`으로 깔고 인물은 SVG로 얹습니다.
- `js/activities.js`: 책마다 해 보기 활동(준비물, 3살·5살 방법, 가 볼 곳과 찾을 것)
- `js/app.js`: 책장, 넘기기, 읽어주기, 시간의 길
- `build.py`: 모든 파일을 한 장짜리 HTML(`dist/wiin.html`)로 묶음

## 새 책 더하기

1. `js/books/`에 `NN-이름.js`를 만들고, 맨 앞에서 `setScene('시대','계절')`을 불러 배경을 정한 뒤 기존 책 하나를 본떠 `BOOKS.push({...})`로 등록합니다. `teaser`는 앞 권 마지막 쪽에 "다음 이야기"로 나오는 한 줄입니다.
2. `era`는 `gojoseon`, `samguk`, `goryeo`, `joseon`, `modern`, `hyeondae` 가운데 하나입니다.
3. `index.html` 아래쪽 `<script>` 목록에 시대 순서에 맞춰 끼워 넣습니다. 권 번호와 다음 권 연결은 이 순서대로 자동으로 정해집니다.
4. 배경은 `hills()`(들판), `palace()`(궁궐), `room()`(방), `yard(y)`(마당), `sea(y)`(바다)를 쓰면 시대와 계절에 맞게 그려집니다.
5. 인물 동작은 `arms`(손 위치를 정하면 팔꿈치가 자동으로 굽음: `aimL` 활쏘기, `writeR` 붓질, `pointR` 가리키기, `flagR` 깃발 들기, `pray`, `carryUp` 등)와 `prop`(손에 쥐는 소품), `stance`(`sit`, `kneel`, `walk`, `run`, `lie`)로 정합니다. 노란 별 티셔츠 아이(`kid`)는 지금 우리 아이에게만 쓰고, 옛날 아이는 `oldKid`, `oldGirl`을 씁니다.
6. 그림을 눌러 보는 장면은 쪽에 `taps:[{label, el, say}]`를 넣고, SVG 안의 해당 부분을 `<g id="el">`로 감쌉니다. `show`, `hide`에 id를 주면 눌렀을 때 그림이 바뀌고, 같은 그림에 여러 동작을 걸면 누를 때마다 차례로 돌아갑니다.

전해 오는 이야기와 기록된 사실은 장면 위 표시와 부모님 메모로 구분했습니다.
