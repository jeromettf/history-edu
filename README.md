# 우리 집 위인 그림책

3살·5살 아이에게 읽어 주려고 만든 한국사 위인 그림책입니다. 「한국을 빛낸 100명의 위인들」에 나오는 인물 가운데 10명을 골라, 동화책처럼 한 장면씩 넘기며 읽도록 만들었습니다.

모든 책은 같은 틀을 따릅니다. 무언가를 좋아한 아이 → 사람들이 겪던 곤란한 일 → 그 사람이 한 일 → 지금 우리 곁에 남은 것. 마지막 쪽에는 3살용·5살용 이야기 나누기 질문과 부모님 메모가 있습니다.

## 구조

- `index.html`: 화면 뼈대와 스타일
- `js/art.js`: 그림 라이브러리 (손그림 질감, 인물, 동물, 소품)
- `js/books/NN-이름.js`: 책 한 권씩. 쪽 배열과 이야기 나누기 질문, 부모님 메모
- `js/app.js`: 책장, 넘기기, 읽어주기, 시간의 길
- `build.py`: 모든 파일을 한 장짜리 HTML(`dist/wiin.html`)로 묶음

## 새 책 더하기

1. `js/books/`에 `11-이름.js`를 만들고 기존 책 하나를 본떠 `BOOKS.push({...})`로 등록합니다.
2. `era`는 `gojoseon`, `samguk`, `joseon`, `modern` 가운데 하나입니다.
3. `index.html` 아래쪽 `<script>` 목록에 파일을 추가합니다.

전해 오는 이야기와 기록된 사실은 장면 위 표시와 부모님 메모로 구분했습니다.
